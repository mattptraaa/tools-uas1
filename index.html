Pasang API key Gemini

Cara mendapatkan API key gratis
  1. Buka aistudio.google.com/apikey dan masuk dengan akun Google.
  2. Tekan Create API key, lalu pilih project Google Cloud yang ada atau buat project baru.
  3. Salin kunci yang muncul dan tempel apa adanya. Kunci baru dari AI Studio diawali AQ., sedangkan kunci lama diawali AIza.
  4. Tempel di kolom di atas lalu tekan Simpan. Ikon kunci di header berubah hijau.

Kalau kunci berawalan AQ. ditolak, buat kunci klasik lewat Google Cloud Console: menu APIs and Services, Credentials, Create credentials, API key, lalu batasi ke Generative Language API.

Kunci hanya disimpan di browser ini dan dipakai langsung ke Google. Jangan bagikan ke orang lain atau tempel di grup. Paket gratis punya batas pemakaian per menit dan per hari, jadi kalau muncul pesan batas tercapai, tunggu sebentar. Admin yang ingin memasang kunci di server cukup mengikuti README.
